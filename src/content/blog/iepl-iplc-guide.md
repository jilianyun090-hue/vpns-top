## 为什么机场线路类型这么重要？

购买机场时，你一定见过这些词：**IEPL专线、IPLC专线、BGP中转、直连**。很多新手看这些术语一头雾水，直接忽略，结果买到的机场晚高峰一塌糊涂。

其实，**线路类型决定了机场稳定性的上限**。理解这些概念，你就能从根本上判断一家机场值不值得买。

---

## 数据从你手机到Google，经历了什么？

```
你的手机 → 国内网络(电信/移动/联通) → 跨境出口 → 海外网络 → Google服务器
                                ↑
                          这里是关键
```

**GFW就在跨境出口处**，负责检测和拦截翻墙流量。不同的机场，选择了不同的方式突破这个关口。

## 四种线路类型详解

### 1. IEPL专线（最稳定，价格较高）

**IEPL = International Ethernet Private Line（国际以太网专线）**

跨境段走运营商的**私有物理光纤**，与公网完全隔离。

```
你 → 国内入口 → [IEPL私有专线] → 海外出口 → 目标网站
                不经过公网 ↑
                GFW无法拦截 ↑
```

**优点：**
- 不经公网，不受GFW管控
- 晚高峰不受公网拥堵影响，速度稳定
- 延迟低（不经过多次中转）
- 敏感时期几乎不受影响

**缺点：** 运营商专线租金昂贵，导致机场价格较高

**代表机场：** 极连云（8元/月）、云图机场（25元/月）、光年梯（7.42元/月）

---

### 2. IPLC专线（最高规格）

**IPLC = International Private Leased Circuit（国际私用出租线路）**

点对点的专用电路，是IEPL的前身技术，安全性和稳定性均为最高规格。

与IEPL的区别：底层技术不同（SDH vs 以太网），但用户体验基本一致。部分机场混用IPLC和IEPL，统称"专线机场"。

---

### 3. BGP中转（平衡型）

**BGP = Border Gateway Protocol（边界网关协议）**

流量先到达国内BGP优化机房，经过三网整合后走公网出境。

```
你 → 国内BGP优化机房 → [公网跨境，经BGP路由优化] → 海外出口
              ↑
        三网（电信/移动/联通）都能快速到达
```

**优点：**
- 三网用户体验一致（不像直连受运营商限制）
- 价格比专线便宜
- 白天体验接近专线

**缺点：** 跨境段仍走公网，晚高峰受拥堵影响，速度比专线下滑明显（30-50%）

**适合：** 轻度用户、预算有限者

---

### 4. 直连（最便宜，不稳定）

流量直接从你的设备连接海外服务器，不经任何中转优化。

**优点：** 成本最低，价格最便宜

**缺点：**
- 完全依赖你本地运营商的国际出口质量
- 移动/联通用户晚高峰可能极差
- 电信CN2用户体验相对好一些

**适合：** 仅作备用或极轻度使用

## 专线机场一定比中转好吗？

**不一定，关键看你的需求：**

**选专线的情况：**
- 每天晚上追剧、刷YouTube、视频会议
- 使用ChatGPT等AI工具需要稳定长连接
- 外贸、远程办公等对稳定性有商业要求

**选中转的情况：**
- 使用频率很低（一周用几次）
- 主要在白天使用
- 预算极为有限

## 警惕：假专线识别方法

市场上存在标榜"IEPL专线"实际走公网中转的欺诈性机场。识别方法：

### 方法一：晚高峰掉速测试

- 真专线：晚高峰速度下降 < 10%
- 假专线/普通中转：晚高峰速度下降 30-60%

### 方法二：延迟稳定性测试

在Clash Verge中持续ping节点30分钟，观察延迟抖动：
- 真专线：抖动 < 5ms
- 假专线：抖动 > 15ms，可能频繁超时

### 方法三：敏感时期表现

敏感时期公网管控加强，真专线几乎不受影响，假专线会明显掉速。
