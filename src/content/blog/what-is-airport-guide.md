## 机场是什么？

很多人第一次听到「机场」这个词，会以为是航空领域的概念。实际上，**机场是科学上网工具的俗称**，指提供代理节点订阅服务的平台。

**为什么叫机场？**

早期的科学上网工具 V2Ray，其默认图标是一架**纸飞机**。而纸飞机从出发到抵达，不就是在「机场」起降吗？所以这类工具逐渐被网友称为「机场」，节点服务商也就叫做「机场」了。

---

## 机场、VPN、梯子有什么区别？

| 概念 | 含义 | 代表工具 |
|------|------|---------|
| 梯子 | 所有翻墙工具的统称 | 机场、VPN、自建节点 |
| VPN | 加密网络隧道，最初用于企业内网 | ExpressVPN、NordVPN |
| 机场 | 专为翻墙设计的代理节点订阅服务 | 极连云、云图、光年梯 |

**关键区别：**

- **VPN**：一个软件包办一切，但协议笨重，在国内极易被GFW检测屏蔽，2026年连通率越来越差
- **机场**：只提供节点订阅（一条链接），需配合客户端使用，但采用Trojan、VLESS、Hysteria2等轻量高混淆协议，抗封锁能力远强于VPN，价格也更低

**简单来说：机场是目前国内90%用户的首选科学上网方案。**

## 机场怎么用？四步快速上手

### 第一步：注册机场账号

选择一家靠谱的机场（本文末有推荐），注册账号并购买套餐。建议新手先选**月付套餐**，试用一个月后再决定是否续费。

### 第二步：下载代理客户端

根据你的设备选择对应客户端：

| 设备 | 推荐客户端 | 下载方式 |
|------|-----------|---------|
| Windows | Clash Verge Rev | GitHub官方发布 |
| macOS | Clash Verge Rev | GitHub官方发布 |
| iPhone/iPad | Shadowrocket（小火箭） | 外区App Store购买 |
| Android | Clash Meta for Android | GitHub官方发布 |

### 第三步：导入订阅链接

在机场用户中心找到「订阅链接」，复制后导入对应客户端：

**以Clash Verge为例：**
1. 打开Clash Verge，进入「订阅」页面
2. 粘贴订阅链接，点击「下载」
3. 进入「代理」页面，选择一个节点
4. 开启「系统代理」开关

**以Shadowrocket为例：**
1. 点击右上角「+」
2. 类型选「Subscribe」，粘贴订阅链接
3. 返回首页，选择节点，开启顶部开关

### 第四步：选择节点开始使用

- **日常浏览/刷社媒**：选香港节点（延迟最低）
- **看Netflix/流媒体**：选对应区域节点（如看美区选美国）
- **使用ChatGPT**：选新加坡或日本节点（原生IP，风控最少）
- **打游戏**：选延迟最低的节点（通常是香港）

## 机场订阅链接是什么？

订阅链接是机场分配给你的**专属URL**，里面包含了你账号对应的所有节点信息。

客户端通过订阅链接：
1. 自动下载全部节点列表
2. 定期更新节点信息（每天或手动更新）
3. 执行测速和延迟测试

**重要注意事项：**
- 订阅链接等同于你的账号凭证，**不要泄露或分享给他人**
- 如果订阅链接泄露，立即在用户中心点「重置订阅」生成新链接

## 机场常见问题解答

**Q: 使用机场安全吗？**
A: 选择正规有口碑的机场，日常合规使用（查资料、看视频、工作学习）风险极低。不要使用免费的不知名机场，往往会泄露隐私。

**Q: 机场会不会跑路？**
A: 任何机场都有跑路风险，防跑路策略：①选择运营2年以上的老牌机场；②新机场只月付，不年付；③保存好机场的TG频道和备用域名。

**Q: 多少流量够用？**
A: 轻度使用（浏览+偶尔看视频）：50-100G/月；中度（YouTube 1080p 每天2小时）：100-200G/月；重度（4K追剧+大量下载）：500G+/月。

**Q: 一个账号能在几台设备上用？**
A: 大多数机场限制同时在线3-5台设备，部分机场不限设备。购买前查看套餐说明。
