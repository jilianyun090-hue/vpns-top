## 机场是什么

在中文网络语境中，“机场”通常指向用户提供代理节点订阅的服务商。用户购买套餐后取得一条订阅链接，再用 Clash、v2rayN、Shadowrocket 等兼容客户端导入，选择机场节点并建立本地代理。

机场不是航空设施，也不是某一个固定软件。服务商负责服务器、线路、流量和账户；客户端负责读取配置、选择节点和在设备上转发网络请求。把这两者分清，是新手正确配置和排查问题的第一步。

## 机场、梯子、VPN 和节点的关系

“梯子”是口语化统称，可能指机场、VPN、自建代理或整套联网方案。“VPN”在技术上是一类虚拟专用网络方案，常用于企业远程接入和隐私保护；日常宣传中，也常被泛指为商业翻墙应用。机场更常采用订阅加第三方客户端的方式交付代理节点。

| 名称 | 在使用链路中的角色 |
|---|---|
| 机场 | 提供账户、套餐、订阅与节点线路 |
| 订阅链接 | 把节点配置交付给客户端 |
| 机场节点 | 可选择的服务器入口和连接参数 |
| 客户端 | 在 Windows、Mac、Android 或 iOS 执行连接 |
| 规则 | 决定哪些请求代理、直连或拦截 |

因此，“机场推荐”和“梯子推荐”不能只推荐一个软件。还需要考虑服务商稳定性、客户端兼容性、使用地区、流量和个人风险承受能力。

## 机场订阅链接是什么

订阅链接是一条包含账户识别令牌的配置入口。客户端通过它获取节点名称、服务器参数、协议和代理组。机场维护或更换线路后，用户更新订阅即可取得新配置，无需逐个手动修改节点。

订阅链接往往足以让他人在自己的客户端使用你的套餐，应视为敏感凭证。不要公开截图、上传在线转换站或发给陌生人代测。详细安全说明见 [机场订阅链接是什么与安全使用](/blog/airport-subscription-link-guide/)。

## 机场节点是什么

机场节点是客户端中可选的连接入口，通常按香港、日本、新加坡、美国或其他地区命名。有些名称还包含线路、协议、倍率或用途提示。

节点地区不等于速度。体验受本地运营商、距离、线路、负载、晚高峰、丢包和目标网站影响。延迟低只代表小请求响应较快，视频还要看持续带宽，游戏和语音还要看抖动与 UDP。

Clash 节点和小火箭节点只是客户端视角的称呼。同一机场可以为 Clash 机场用户提供 Clash 格式，也能为小火箭机场用户提供通用或 Shadowrocket 格式。

## 新手使用机场的完整流程

### 第一步：明确用途和预算

先判断主要用于资料查询、视频、远程工作、实时通信还是地区内容。估算每月流量、设备数量和是否需要多地区节点。新手优先短周期购买，不要在无法验证服务时直接长期预付。

### 第二步：选择可核验的机场

查看套餐说明、节点倍率、设备限制、流量重置、退款规则、服务渠道和运营记录。不要只看“节点很多”“超低价”“永久套餐”等营销词。任何机场都存在维护、政策和经营风险，准备备用方案比追求绝对稳定更现实。

### 第三步：选择兼容客户端

- Windows 可根据机场格式选择 Clash 兼容客户端或 v2rayN；
- Mac 关注系统代理、网络扩展和芯片兼容；
- Android 关注订阅格式、分应用与后台限制；
- iPhone、iPad 常用 Shadowrocket 等兼容工具。

具体教程：

- [Windows 机场客户端与 Clash 节点配置](/blog/windows-airport-client-guide/)
- [Mac 机场客户端选择与配置](/blog/mac-airport-client-guide/)
- [Android 机场客户端选择与导入](/blog/android-airport-client-guide/)
- [小火箭节点订阅与更新](/blog/shadowrocket-subscription-import-guide/)

### 第四步：导入订阅

从机场用户中心复制与客户端匹配的订阅，在配置或订阅页面从 URL 导入。下载后将配置设为活动配置，进入代理组选择节点。Clash 用户可参考 [Clash 机场订阅导入教程](/blog/clash-subscription-import-guide/)。

### 第五步：开启代理并验证

先用规则模式和普通系统代理测试两个 HTTPS 网站。浏览器稳定后，再测试其他应用、TUN、分应用或特殊地区服务。首次配置不要同时修改 DNS、规则和多个高级功能。

## 规则、全局和直连有什么区别

规则模式根据域名或 IP 决定代理与直连，适合日常使用；全局模式让大部分流量走所选节点，适合短时排查规则；直连模式用于确认原始网络。

一个实用判断是：直连失败先修本地网络；全局成功、规则失败看分流；浏览器成功、桌面应用失败看系统代理覆盖与 TUN。完整故障流程见 [机场连接后部分应用无法联网](/blog/airport-connection-troubleshooting/)。

## 节点地区怎么选

日常浏览先测试物理距离较近的地区，再根据目标内容选择。不要把固定延迟区间当作所有网络的标准，同一城市的不同运营商表现也可能不同。

选择原则：

- 普通浏览：优先稳定和低波动；
- 视频：关注持续带宽、地区和内容许可；
- 游戏与语音：关注延迟、抖动、丢包与 UDP；
- AI 和网页服务：还要考虑目标服务地区与账户政策；
- 大流量任务：关注倍率、套餐和公平使用规则。

机场倍率会影响扣费，详见 [机场节点倍率是什么](/blog/node-multiplier-guide/)。

## 如何估算流量

文字浏览和消息通常消耗较少，高清视频、云盘同步、系统更新和测速消耗更大。无法用一个固定数字覆盖所有用户，最好查看自己设备过去一个月的网络统计，再预留余量。

注意上传是否计费、节点倍率以及多设备共享。全局代理可能让系统更新和国内流量也经过机场。使用规则分流并关闭不必要的后台任务，有助于控制消耗。

## 机场安全与隐私边界

机场不是绝对匿名工具。服务商可能看到连接元数据，非 HTTPS 内容的风险更高。选择有透明规则和正常支持渠道的服务，优先访问 HTTPS 网站，不通过不可信节点传输敏感明文数据。

还应做到：

- 使用独立密码并保护邮箱找回方式；
- 不公开订阅、配置和完整日志；
- 不安装来源不明客户端、证书和脚本；
- 旧设备出售前删除订阅；
- 订阅泄露后在用户中心重置；
- 遵守当地法律法规与所访问服务条款。

## 如何降低机场跑路和失联风险

任何服务都不能保证永远运营。降低风险的方式包括先月付验证、避免一次充值过多、保存官方公告和备用域名、重要工作准备独立备用方案，以及不把唯一联系方式放在同一服务内。

“运营多年”“用户很多”可以作为参考，但不能替代持续观察。机场推荐文章若只强调价格和速度而不讨论付款周期、服务响应和风险，不够完整。

## 新手常见故障

### 导入后没有节点

检查套餐、订阅格式、活动配置和筛选条件，参考 [机场节点不显示排查](/blog/airport-nodes-not-showing-fix/)。

### 所有节点超时

验证直连网络，更新订阅，换两个节点和一种网络，参考 [机场无法连接与超时排查](/blog/airport-connection-timeout-fix/)。

### Clash 配置错误

确认使用 Clash 专用订阅，禁用本地覆写后重试，参考 [Clash 配置错误排查](/blog/clash-config-error-fix/)。

### 晚上明显变慢

排除家中 Wi-Fi 和后台下载，做同节点不同时段记录，参考 [机场晚高峰卡顿怎么办](/blog/airport-peak-hours-fix/)。

## 购买前核验清单

- [ ] 套餐价格、周期与流量清楚；
- [ ] 常用地区和协议与客户端兼容；
- [ ] 节点倍率、上传计费和流量重置明确；
- [ ] 设备数与同时在线限制符合需求；
- [ ] 有正常帮助文档、公告和工单渠道；
- [ ] 先用短周期或试用验证；
- [ ] 重要任务有备用网络方案；
- [ ] 不把营销测速当成长期表现。

## 常见问题

### 机场和 VPN 哪个更好？

取决于设备、地区、易用性、协议与用途。商业 VPN 通常集成客户端，机场更依赖订阅与第三方工具。应根据实际可用性和风险选择。

### 一个机场订阅能用几台设备？

由套餐设备数和同时在线规则决定。多设备会共享流量，不要默认不限设备。

### 机场节点越多越好吗？

不一定。节点维护、线路差异和可用率比纯数量重要。大量重复节点还会增加选择成本。

### 免费节点梯子能长期使用吗？

免费来源常缺乏稳定性、隐私说明和支持，不建议用于敏感账户或长期工作。不要为免费配置授予高风险证书权限。

### 机场是否可以保证所有网站都能访问？

不能。目标服务地区限制、账户风控、平台故障和法律政策都会影响结果，机场只负责其中的网络路径部分。

## 总结

机场是一种通过订阅向客户端交付代理节点的服务。新手应分清服务商、订阅、节点、客户端和规则五个层次，再按用途选择套餐和工具。先短期验证、保护订阅、使用规则分流，并掌握基础排查流程，比单纯追求最低价格、最多节点或夸张测速更可靠。
